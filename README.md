Bangla Scientific Calculator

A fully functional scientific calculator written in C/C++ with a Bangla user interface.  
Supports basic arithmetic, advanced scientific functions, memory operations, and proper error handling.

---

 Features

Basic Arithmetic
- যোগ (+), বিয়োগ (−), গুণ (×), ভাগ (÷)

 Scientific Functions
- ঘনমূল (√), ঘাত (^)
- Trigonometric: sin(x), cos(x), tan(x), cot(x), sec(x), cosec(x)
- Inverse trigonometric: asin(x), acos(x), atan(x)
- Logarithmic: log(x), ln(x)
- Exponential: exp(x)
- Factorial: !
- Absolute value: abs(x)
- Constants: π, e

 Memory Operations
- M+ – Add to memory  
- M- – Subtract from memory  
- MR– Read memory  
- MC – Clear memory  

 User Interface
- Fully in **Bangla language
- Menu-driven interface
- Looping menu until user chooses exit

Error Handling
- Division by zero  
- Invalid input (e.g., letters instead of numbers)  
- Domain errors for functions (e.g., square root of negative numbers)
